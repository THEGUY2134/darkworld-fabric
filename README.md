# Dark World — Fabric 1.21.1

A Minecraft Java mod project targeting Fabric and Minecraft 1.21.1.

## Build without installing anything

Every push to `main` runs the GitHub Actions build. Open the **Actions** tab, choose the latest **Build Dark World Mod** run, and download the `darkworld-mod` artifact if the build succeeds.

## Current prototype features

- Registers a Dark Fountain block and item.
- Adds a custom Dark World dimension data definition using the dark forest biome.
- Using a Dark Fountain attempts to teleport the player to the Dark World.

This is an early prototype, not a finished release. Card Kingdom terrain and structures, the Card King boss and attacks, a return fountain, custom sounds, and original textures remain to be implemented and tested in-game.
